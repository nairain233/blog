Rain 是一个基于现代 Xposed API 的免费模块，面向已适配的 Android 应用提供体验优化，管理界面采用 Jetpack Compose 与 Miuix。

## 主要功能

- 减少广告干扰，跳过部分应用的开屏广告，移除已适配的广告与推广内容。
- 精简应用界面，清理营销入口和冗余布局。
- 提供已适配应用的本地功能调整，并在模块内管理应用作用域。
